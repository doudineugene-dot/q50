# Установка пакета на головное устройство

## 0. Перед установкой — проверить совместимость

Две причины, по которым пакет не встаёт, видны заранее:

```bash
aapt dump badging apk/имя-версия.apk | grep -E 'sdkVersion|native-code'
```

- `sdkVersion` (minSdk) выше версии Android на ГУ → пакет не установится;
- `native-code` содержит только `arm64-v8a`, а система 32-битная → не запустится.

Версию Android и архитектуру своего ГУ запишите в `README.md`, чтобы не проверять
каждый раз заново.

## 1. Разрешить установку из неизвестных источников

Без этого система откажется ставить пакет не из штатного магазина.

- **Android 7 и старше:** Настройки → Безопасность → «Неизвестные источники».
- **Android 8 и новее:** разрешение выдаётся отдельно каждому приложению-установщику
  (файловому менеджеру, браузеру) — Настройки → Приложения → нужное приложение →
  «Установка неизвестных приложений».

## 2. Способ A — через USB-накопитель

Подходит, когда до ГУ нет доступа по adb.

1. Скопировать `.apk` на флешку (FAT32 — читается практически всегда).
2. Вставить флешку в USB-порт машины.
3. Открыть на ГУ файловый менеджер, найти файл, запустить установку.

Если штатного файлового менеджера нет — его самого придётся поставить первым,
и тогда без способа B не обойтись.

## 3. Способ B — через adb

Надёжнее: видно текст ошибки, если установка не прошла.

```bash
adb devices                          # устройство должно быть в списке
adb install -r apk/имя-версия.apk    # -r = переустановка поверх имеющейся
```

По Wi-Fi, если ГУ в одной сети с компьютером:

```bash
adb connect <ip-адрес-гу>:5555
adb install -r apk/имя-версия.apk
```

Полезное рядом:

```bash
adb shell pm list packages | grep <имя>   # проверить, что пакет встал
adb uninstall <имя.пакета>                # удалить
adb logcat | grep -i <имя.пакета>         # смотреть, почему падает при запуске
```

## 4. Типичные ошибки adb

| Сообщение | Причина | Что делать |
|---|---|---|
| `INSTALL_FAILED_OLDER_SDK` | minSdk пакета выше версии Android на ГУ | Искать сборку постарше |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | Пакет только под `arm64`, система 32-битная | Взять `armeabi-v7a`-сборку или universal |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | Уже стоит версия с другой подписью | Сначала `adb uninstall <имя.пакета>` |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | Ставится версия ниже установленной | Удалить текущую версию и поставить заново |
| `INSTALL_PARSE_FAILED_NO_CERTIFICATES` | Пакет не подписан | Файл битый или пересобран без подписи — не ставить |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | Нет места | Освободить память на ГУ |
