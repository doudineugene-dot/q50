# Как добыть публичный сертификат OBU

Для сборки `.epk` нужен **публичный сертификат OBU** (закрытый ключ DCU не
нужен — подтверждено). Сертификат публичный, поэтому его не надо взламывать —
надо найти файл. Ниже пути от самого простого к сложному.

## Чего делать НЕ нужно

Вычислить ключ из имеющихся `.epk` **невозможно**. Поле `m_key` — это
случайный сеансовый ключ, зашифрованный открытым ключом OBU. Модуль RSA из
шифротекстов не восстанавливается (это работало бы для подписей с известным
текстом, но здесь шифрование случайного значения). Новые образцы `.epk`
ключ не выдадут — не тратьте на это время.

## Путь 1 — упаковщик AppGarage (самый вероятный)

Один из образцов называется `appgarage-dash-v1.0.epk`. Значит существует
инструмент **AppGarage**, которым энтузиасты собирают пакеты. Сертификат OBU
почти наверняка **зашит внутри него** — иначе он не смог бы собирать `.epk`.

Даже если сам `.cer` потерян, он остаётся в бинарнике/ресурсах упаковщика:

```bash
tools/certscan.py путь/к/AppGarage -o found/
```

Спросить у энтузиаста: **чем именно он паковал** и где взял этот инструмент.
Файл сертификата ему искать не обязательно — достаточно самого упаковщика.

## Путь 2 — прошивка ГУ

Устройство проверяет пакеты, значит сертификат лежит в прошивке. Взять дамп
прошивки (обновление с сайта Infiniti, дамп eMMC/NAND) и прогнать:

```bash
tools/certscan.py firmware.bin -o found/
```

Если внутри сжатые/зашифрованные разделы — сперва распаковать их, потом
сканировать. Сканер ищет и вкраплённые в бинарь ключи, не только отдельные
файлы.

## Путь 3 — файловая система устройства

Если ГУ с root, сертификат лежит файлом. Приложение **Q50 Info 1.2** само
обходит типовые каталоги (`/etc`, `/system/etc/security`, `/vendor/etc` и др.)
и показывает найденные `.cer/.crt/.pem/.der` и файлы с DER-сигнатурой X.509.
Вытащить кандидатов с устройства и проверить сканером.

## Что делать с находкой

Любой найденный сертификат/ключ проверить на пригодность:

```bash
tools/epktool.py pack любой.apk -o test.epk --rsa-pub found/cert-001.pem --mode cbc
```

Ключ OBU — **RSA-1024** (128 байт = `m_keySize` в EPK). Сканер помечает такие
находки. Ключи другого размера — не то.

Настоящую проверку даёт только устройство: собрать `.epk` найденным
сертификатом и посмотреть, примет ли его ГУ. Примет — сертификат верный и
режим AES угадан; отвергнет — пробовать другой режим (`--mode ctr`) или
другой кандидат.
