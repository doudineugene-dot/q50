# Контейнер `.epk` головного устройства Q50 (InTouch)

Формат **полностью подтверждён**: раскладка, шифрование и режим сверены с
открытой реализацией [qazwsd147/appgarage-dash](https://github.com/qazwsd147/appgarage-dash)
(MIT, © bugjosh), которая воспроизводит его по декомпилированному
`framework.jar` (`com.connexis.ivi.utils.epk.v2`). Раскладка независимо
проверена разбором двух реальных образцов (`gtr.epk`, `appgarage-dash-v1.0.epk`).

## Установка

ГУ (AppManager, `com.connexis.appsmanager`) устанавливает нативные приложения
с USB **только** упакованными в `.epk` — голый APK не распознаётся. `.epk`
кладётся в корень FAT32-флешки и выбирается в AppManager.

## Раскладка

```
заголовок:
  0x000  4    ".epk"
  0x004  2    version      u16 BE = 2
  0x006  2    payloadType  u16 BE   (loader не проверяет)
  0x008  2    blockCount   u16 BE   число вложенных файлов
  0x00A  2    keySize      u16 BE = 128 (RSA-1024)
  0x00C  256  ключ: RSA(dataKey) слева, нули справа
далее blockCount раз:
  128  имя файла, ASCIIZ
  4    длина шифроблока, int32 BE
  ...  шифротекст
```

## Шифрование (подтверждено кодом)

| Что | Как |
|---|---|
| dataKey | 20 случайных байт, добитые нулями до 32 → ключ **AES-256** |
| Шифр нагрузки | **AES-256-CBC** |
| IV | фиксированный: `01 23 45 67 89 ab cd ef` + восемь нулей |
| Паддинг | **PKCS5** (добавляет 1..16 байт всегда) |
| Обёртка ключа | **RSA / PKCS#1 v1.5**, открытый ключ OBU: `dataKey` → 128 байт |
| Подпись / MAC | **нет** — только конфиденциальность |

Фиксированный IV и режим по одним зашифрованным файлам определить нельзя —
они взяты из кода. Именно поэтому раньше режим оставался неизвестным.

## Почему сборка возможна без секретов

`m_key` — сеансовый `dataKey`, завёрнутый **открытым** ключом OBU. Завернуть
можно только открытым ключом, поэтому:

| Задача | Нужен ключ |
|---|---|
| Собрать свой `.epk` для установки | **публичный** сертификат OBU |
| Распаковать чужой `.epk` | закрытый ключ OBU (в прошивке, не публикуется) |

Подписи в формате нет, так что публичного сертификата **достаточно** для
сборки пакета, который ГУ примет. Сертификат лежит в `../keys/obu_cert.pem`.

## Совместимость

Собранный `.epk` загрузится только на ГУ, чья прошивка несёт парный закрытый
ключ OBU. Целевая платформа: **InTouch на Android 2.3.7 (API 10, x86)**,
проверено на 2018 Q60 Red Sport. На других годах/регионах может понадобиться
свой сертификат (см. `../keys/README.md`).

## Проверка инструментом

```bash
tools/epktool.py info    epk/q50info-1.2.epk         # разбор заголовка и блоков
tools/epktool.py build   app.apk -o app.epk --cert keys/obu_cert.pem
tools/epktool.py parse   app.epk -o out/ --key obu_key.pem   # нужен закрытый ключ
tools/epktool.py compare a.epk b.epk
```

`epktool.py` — самостоятельная реализация того же формата (не копия чужого
кода). Проверена: разбирает реальный `gtr.epk` со сходящимся размером, а
сквозной тест build→parse на своей паре ключей RSA-1024 даёт APK байт в байт.
