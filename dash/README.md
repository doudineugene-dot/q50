# Q50 Dash — приборка

Гоночная приборка для головного устройства **Infiniti InTouch** (V37 Q50/Q60,
Android 2.3.7, x86). Читает сигналы CAN, которые ГУ отдаёт как Android-сенсоры
(вендор Ygomi, `VS_ID_*`, типы 12–53), и рисует калиброванные шкалы. Чистая
Java, без нативного кода — идёт на x86 API-10.

## Что показывает

- **Тахометр-дуга** с красной зоной (редлайн VR30DDTT 6800) и цифрой оборотов.
- Плитки: **давление масла** (бар), температура масла, ОЖ, момент, скорость,
  боковое G. Цвет значения меняется на жёлтый/красный при выходе за пороги.
- Сигналы читаются **по имени** (`VS_ID_*`), поэтому приборка сама подхватывает
  те, что есть на вашей машине; наддув/передача/мощность подключатся, если
  соответствующий сигнал присутствует.

## Калибровка

Из открытого проекта `qazwsd147/appgarage-dash` (MIT), проверено на VR30DDTT:

| Сигнал | Пересчёт |
|---|---|
| RPM, температуры (°C), скорость (км/ч), момент (Нм) | напрямую |
| давление масла (тип 16) | сырое × 10 = бар (× 145 = psi) |
| мощность (тип 32) | сырое × 1.047e-4 = кВт |
| боковое/продольное ускорение | в g |

Калибровки и пороги — в `src/com/q50/dash/Signals.java`, их легко поправить.

## Сборка

```bash
./build.sh                                    # -> build/q50dash-1.0.apk
../tools/epktool.py build build/q50dash-1.0.apk -o q50dash.epk --cert ../keys/obu_cert.pem
```

`.epk` кладётся в корень USB (FAT32) и выбирается в AppManager на ГУ.
