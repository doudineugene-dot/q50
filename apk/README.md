# apk/

Установочные пакеты.

**Именование:** `имя-версия.apk` — например `maps-11.2.0.apk`.
Версия в имени обязательна: без неё через полгода не отличить, что за файл лежит.

**Контрольные суммы** — в `SHA256SUMS`. Добавить и проверить:

```bash
sha256sum apk/имя-версия.apk >> apk/SHA256SUMS
sha256sum -c apk/SHA256SUMS
```

**Перед добавлением** посмотрите `minSdk` и архитектуру пакета и занесите их
в `../CATALOG.md`:

```bash
aapt dump badging apk/имя-версия.apk | grep -E 'sdkVersion|native-code'
```
