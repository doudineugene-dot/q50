# q50

Хранилище APK-файлов для штатной мультимедийной системы **Infiniti Q50** (InTouch).

> Репозиторий личный: собираю здесь установочные пакеты, их версии и заметки о том,
> что реально заработало на машине, а что нет.

## Что внутри

| Путь | Назначение |
|---|---|
| [`CATALOG.md`](CATALOG.md) | Таблица всех пакетов: версия, размер, источник, статус проверки |
| [`apk/`](apk/) | Сами `.apk`-файлы |
| [`docs/install.md`](docs/install.md) | Как залить и установить пакет на ГУ |

## Моя система

Заполнить под свою машину — от этого зависит, какие пакеты вообще встанут:

- **Модель / год:** Infiniti Q50 `____`
- **Головное устройство:** InTouch `____`
- **Версия Android:** `____` (API level `____`)
- **Архитектура:** `____` (armeabi-v7a / arm64-v8a)
- **Разрешение нижнего экрана:** `____`
- **Root:** есть / нет

Версия Android и архитектура — главный фильтр. Пакет с `minSdk` выше системного
не установится вообще, а `arm64`-сборка не запустится на 32-битном ГУ.

## Как добавить пакет

1. Положить файл в `apk/` по схеме `имя-версия.apk` (например `maps-11.2.0.apk`).
2. Дописать строку в [`CATALOG.md`](CATALOG.md).
3. Записать контрольную сумму — чтобы потом отличить свой файл от подменённого:

   ```bash
   sha256sum apk/имя-версия.apk >> apk/SHA256SUMS
   ```

4. Закоммитить и запушить.

## Хранение бинарников

APK — это бинарные файлы, и обычный git с ними обращается плохо: каждая новая версия
целиком добавляется в историю и остаётся там навсегда. Репозиторий распухает,
клонирование замедляется. Плюс жёсткие лимиты GitHub: предупреждение на **50 МБ**
и отказ принять файл больше **100 МБ**.

**Рекомендуемый способ — GitHub Releases.** Файлы лежат вне git-истории, лимит
**2 ГБ** на файл, не тратится квота LFS, и на каждый файл есть прямая ссылка для
скачивания:

```bash
gh release create v1 apk/*.apk --title "Сборка 1" --notes "Первый набор пакетов"
```

**Альтернатива — Git LFS**, если нужно версионировать пакеты прямо в дереве
репозитория. В `.gitattributes` правило уже прописано, но оно не сработает само:
на своей машине нужно один раз выполнить

```bash
git lfs install
```

иначе файлы уйдут в репозиторий обычными блобами и правило будет проигнорировано.
Учтите квоту бесплатного тарифа: 1 ГБ хранилища и 1 ГБ трафика в месяц.

## Оговорка

Репозиторий приватный и предназначен для личного использования на собственной машине.
Выкладывайте сюда только те пакеты, которые вы вправе хранить и распространять:
собственные сборки, свободное ПО, официальные дистрибутивы.

Установка стороннего ПО на штатное головное устройство выполняется на свой риск и
может повлиять на гарантию.
